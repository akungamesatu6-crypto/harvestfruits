# 🍓 HarvestFruit

A fun HTML5 fruit-catching browser game. Catch falling fruits in your basket, score points, and survive as long as you can!

**Live at:** https://harvestfruit.fun/

## Features
- 7 fruit types with different point values
- Golden fruits worth 50 points  
- Rotten fruits that cost a life — avoid them!
- Progressive difficulty
- Mobile touch support
- 3 lives system

## Built With
- React + TypeScript
- HTML5 Canvas API
- Vite + Tailwind CSS
